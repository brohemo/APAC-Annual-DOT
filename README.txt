APAC Dry Van Trailer Inspection - v1.0

Files: index.html, manifest.webmanifest, sw.js, icon.svg.

Quick start: Open index.html locally in Chrome/Edge for a preview and local recordkeeping. For an installable/offline PWA, host the entire folder on an HTTPS website (GitHub Pages is suitable for testing), open the HTTPS URL, then use browser Install/Add to Home Screen. After first online load, service worker caches application files.

Important: Inspection data is stored in IndexedDB in the specific browser on the specific device. No cloud synchronization, login, user authentication, central permissions or server backups in this version. Use Records > Export complete JSON backup frequently. Browser data clearing or device replacement may destroy records.

Annual inspection: Qualified inspector requirements 49 CFR 396.19; report 396.21; minimum periodic items 396 Appendix A. Verify the precise vehicle configuration and standards before relying on the app for regulated reporting. This is not an official certification service.
